# Code of conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, insults, or personal or political attacks, in issues, pull requests, discussions or anywhere else the project lives.
- Welcome newcomers. Everyone started with a first pull request.

If something here makes you uncomfortable, contact the maintainer privately through a [GitHub security advisory](https://github.com/iambashar/agent-intercom/security/advisories/new) or by email (address in the commit history). Reports are kept confidential. The maintainer may remove content or block participants who don't follow this code.
